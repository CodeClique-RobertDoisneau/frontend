## Présentation

Interface web du projet **CodeClique**, développée avec **Angular**.

## Packages principaux

- **SCSS** : personnalisation du thème et des composants
- **Angular Material** : composants UI et thèmes réactifs
- **NotebookJS** : rendu des notebooks Jupyter au format HTML
- **Thebe** + **Pyodide** : exécution de code Python côté client (WebAssembly)

## Installation locale

L'installation est **la même** que pour tout projet **Angular**. Mais nous proposons une méthode de déploiement adaptée au projet dans le dépôt `CodeClique-RobertDoisneau/deployment`.

## Règles de contribution

Utiliser le fichier `.editorconfig` ou voici un résumé des règles:
- **Indentation** : deux espaces
- Insérer une **nouvelle ligne** en **fin de fichier**
- Fichiers `.ts` : préférer les simples apostrophes `'`
- Pas de **whitespace characters** en fin de ligne
