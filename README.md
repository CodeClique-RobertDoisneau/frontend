## Présentation

Interface web du projet **CodeClique**, développée avec **Angular**.

## Packages principaux

- **SCSS** : superset css
- **Angular Material** : composants UI et thèmes réactifs
- **Pyodide** : exécution de code Python côté client (WebAssembly)

## Installation locale

L'installation est **la même** que pour tout projet **Angular**.
Mais nous proposons une méthode de déploiement adaptée au projet dans le dépôt `CodeClique-RobertDoisneau/CodeClique`.
